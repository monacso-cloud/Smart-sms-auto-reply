# ReplyDesk Support — Draft

## Before contacting support
Use Test Your Bot to confirm keyword and numbered-menu replies before enabling automation.

Check:
- Master Auto Reply is on.
- Missed Call and/or Incoming SMS is enabled.
- Reply Schedule allows the current day and time.
- The correct SIM is selected.
- Required Android permissions are granted.
- Your numbered menu and keyword replies are saved.
- STOP has not been used by the recipient if chatbot replies are expected.

## Common issues

### Missed call did not receive a reply
Check Missed Call replies, schedule, permissions, SIM selection, repeat interval and carrier SMS availability.

### SMS keyword did not match
Use Test Your Bot and add additional words customers may use for the same question.

### Numbered menu did not reply
Confirm Enable numbered menu is on and the selected option has both a label and a reply.

### Logs are missing
Check the selected log period and Android Call Log permission. ReplyDesk-owned logs may have been removed by the configured retention period.
